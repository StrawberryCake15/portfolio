DAVIN THE PROJECT — BUILD 01 SOURCE PACKAGE

FILES
- index.html: five-page portfolio structure and content
- style.css: layout, colors, transitions, sprite strip, and pixel cursors
- Davin.js: navigation, trainer card, mobile menu, build selection, Lab controls, and sprite behavior
- assets/davin.jpg: profile portrait used by the profile peek and trainer card
- sprites/*.png: the 30 supplied sprite images

HOW TO UPDATE YOUR PROJECT
1. Extract this ZIP.
2. Keep index.html, style.css, Davin.js, assets/, and sprites/ together in one folder.
3. To update an existing project, replace its index.html, style.css, and Davin.js with these versions.
4. Keep the assets and sprites folders beside index.html. Do not rename the image files.
5. Open index.html in a browser.

The HTML references style.css and Davin.js by these exact filenames. Image paths are relative to index.html.
